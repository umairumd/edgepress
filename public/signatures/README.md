## Placeholders to replace

For each team member, replace:

- `[Your Name]` – Full name  
- `[Your Title]` – Role (e.g. Founder, Creative Director, Project Manager)  
- `[your.email@inomadigital.com]` – Personal email (or keep `info@inomadigital.com`)  
- `[+92-XXX-XXXXXXX]` – Personal or team phone  

## How to use

1. Open the chosen `.html` file in a browser or text editor.
2. Replace all placeholder text.
3. Copy the full HTML (Ctrl+A, Ctrl+C).
4. In your email client:
   - **Gmail**: Settings → See all settings → General → Signature → paste HTML (or use an extension that accepts HTML).
   - **Outlook**: File → Options → Mail → Signatures → New → paste.
   - **Apple Mail**: Preferences → Signatures → create new → paste (may need to paste as rich text).
   - **Others**: Look for a “signatures” or “HTML” option and paste the code.

## Dark / light backgrounds

Each signature uses a white background (`#ffffff`), so it stays readable in light and dark email themes. The logo used is the dark version, which works on this white background.

For dark-mode-only use (e.g. if you know recipients use dark themes), you can swap the logo URL to `inoma-logo-light.png` and adjust text/icon colors to light.

## Compatibility

- **Gmail, Apple Mail, Yahoo Mail**: Full support.
- **Outlook (desktop)**: SVG icons may not render; use Variation 1 or 3 (text links) if icons are missing.
- **Outlook (web)**: Generally supports the layout and PNG logo; SVG icons may vary.

## Converting SVG icons to PNG (optional)

If some clients block SVG icons, convert them to PNG (e.g. 36×36px) and host at:

- `https://www.inomadigital.com/signatures/icon-linkedin.png`
- etc.

Then replace the `.svg` URLs in the HTML with the `.png` versions.
